One joke about Monday mornings, in 200 characters or less — because even the alarm clock dreads the start of the week.

> My alarm clock checked the calendar Monday morning, sighed, and hit snooze on itself — even it refuses to start the week.

## Run it

```sh
node main.ts
```

This writes the entry to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
